# Historical Working Draft package 0.2

**Class:** Source and review archive  
**Status:** Historical preparatory Working Drafts; not adopted

This snapshot preserves the nine 0.2 TeX documents, shared preamble, manifest, build/check/change-register tools, Programme Brief 0.4, expanded review and its requirement change register. [snapshot.json](snapshot.json) records original paths, archived paths and SHA-256 digests. It is the fixed baseline for the [substantive validation cycle](../../../docs/reviews/validation_0.2/README.md).

The archived package contains 753 requirement identifiers and originally compiled to 225 pages. The local [PDFs and build/check reports](../../../build/archive/0.2/) were copied before revision; generated artifacts are ignored and may be absent in a fresh checkout.

To reproduce PDFs, invoke this archive's `tools/build_publications.py` using the archived layout. It resolves the archive root and uses its preamble and manifest. Do not substitute the current presentation source. Contextual links to main-repository manuscripts and planning documents are documentary references, not TeX inputs. Archived comparison/check tools retain their historical behavior; the current tools support subsequent baselines and archive-integrity checking.

The [original 0.2 review](docs/reviews/expanded_working_draft_review.md) is preserved byte-for-byte. Its relative navigation describes its original repository location; use the main repository's historical review or the links above for navigation from this archive.
