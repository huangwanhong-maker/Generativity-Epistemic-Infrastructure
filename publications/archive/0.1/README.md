# Historical Working Draft package 0.1

**Class:** Source archive  
**Status:** Historical preparatory Working Drafts; not adopted

This snapshot preserves the nine 0.1 TeX documents, their shared preamble, manifest and build/check scripts before expansion to 0.2. [snapshot.json](snapshot.json) records original paths, archive paths and SHA-256 digests. The preceding [review record](../../../docs/reviews/initial_working_draft_review.md) describes the 84-page, 318-requirement package.

Sources retain their original relative paths. To reproduce this edition, run the archived build script from this archive root or use a separate copy preserving this layout. It resolves its own root and writes a separate `build/publications/` here. Do not substitute the current programme preamble: that would create a different rendering. An archived source may mention a root-level source map or manuscript that remains in the main repository; those references are documentary, not TeX inputs.

The existing local 0.1 PDFs and reports were copied to [build/archive/0.1](../../../build/archive/0.1/) before the current build changed. They are ignored generated artifacts, not guaranteed to be present in a fresh checkout. The new [current package](../../README.md) has a separate review and requirement change register.
