# GR-SPEC-120 — Generativity Information Model Specification

**Document class:** Specification  
**Status:** Experimental implementation draft 0.2; not an adopted Standard

The [experimental record graph and module model](GR-SPEC-120.md) defines a bounded record envelope, overlapping roles, first-class relation incidence, versioned modules, retained material descriptors, projection and explicit legacy migration. The [independent Python package](../../applicative_infrastructure/common/packages/gsp_record_protocol/README.md) supplies JSON Schema, scoped validation, transaction preparation, graph projection, fixtures and a CLI.

Protocol `gsp-record-protocol/0.2`, schema `gsp-workspace/0.2` and profile `gsp.general/0.2` are experimental identifiers. They do not imply adoption of the GR Working Drafts or independent academia interoperability. See the [publication taxonomy](../../docs/framework/publication_taxonomy.md), [implementation design](../../docs/planning/graph_workspace_design.md), and [source review](../../docs/planning/graph_semantics_review.md) for authority, scope and remaining limits.
