# GR-200 — Epistemic Recording Framework

> **Developed draft available:** [Working Draft 0.3 source](GR-200.tex) and [compiled PDF](../../build/publications/GR-200.pdf). The Markdown outline below is retained as historical planning context; its candidate choices are not adopted. Current requirements and unresolved decisions are in the TeX draft.

**Document class:** Standards-track project outline  
**Status:** Preliminary; not an adopted Standard

Provisional scope:

- observations;
- traces;
- claims;
- evidence;
- interpretations;
- judgments;
- attribution;
- perspectives;
- uncertainty;
- contestation;
- revision.

This standard should clarify how epistemic status is represented without collapsing it into the underlying event or entity record.
