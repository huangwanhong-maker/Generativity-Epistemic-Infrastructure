# GR-120 — Generativity Information Model

**Document class:** Standards-track project outline  
**Status:** Preliminary; not an adopted Standard

The [bounded Working Draft 0.1](GR-120.md) develops record identity, overlapping roles, first-class relations and module interpretation requirements. The earlier outline below is retained. [GR-SPEC-120](../../specifications/GR-SPEC-120-information-model/GR-SPEC-120.md) supplies the experimental technical realization.

Define the implementation-neutral conceptual information model.

Expected concerns:
- typed records;
- relations;
- identifiers;
- temporal semantics;
- versions;
- provenance;
- perspectives;
- uncertainty;
- branching.
