# GR-310 — Rights, Duties, and Procedural Profiles

**Document class:** Standards-track project outline  
**Status:** Exploratory; not an adopted Standard

Potential profiles may address:

- access;
- correction;
- annotation;
- objection;
- restriction;
- preservation;
- destruction;
- notice;
- review;
- procedural fairness.

Any jurisdiction-specific implementation should be separately profiled and legally reviewed.
