# GR-130 — Generativity Interchange Specification

**Document class:** Standards-track project outline  
**Status:** Preliminary; not an adopted Standard

The [bounded Working Draft 0.1](GR-130.md) states implementation-neutral interchange requirements. Its title clarifies the standards-track role of GR-130; the historical outline below retains its original wording. The separate [GR-SPEC-130](../../specifications/GR-SPEC-130-interchange/GR-SPEC-130.md) supplies the experimental Git/HTTP binding.

Define machine-readable interchange.

Candidate representations:
- JSON-LD;
- RDF;
- YAML;
- schema validation.
