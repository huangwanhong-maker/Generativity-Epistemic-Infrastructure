# GR-300 — Jurisprudential Interface

**Document class:** Standards-track project outline  
**Status:** Preliminary; not an adopted Standard

This document is expected to define a standards-facing interface to legal and jurisprudential use.

Potential topics:

- legal metadata;
- evidentiary status;
- attribution;
- procedural history;
- contested records;
- correction and annotation;
- jurisdictional profiles.

It should not attempt to create substantive legal obligations by itself.
