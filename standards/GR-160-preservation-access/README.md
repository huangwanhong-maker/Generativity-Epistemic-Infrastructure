# GR-160 — Preservation, Privacy, Access, and Retention

**Document class:** Standards-track project outline  
**Status:** Preliminary; not an adopted Standard

The [bounded Working Draft 0.1](GR-160.md) develops retained-material descriptors, historical byte access, detachment/erasure distinctions and declared preservation limits. The earlier outline below remains the broader project scope.

Define preservation states, access controls, sealing, restriction, anonymization, retention, deletion, and long-term interpretability.
