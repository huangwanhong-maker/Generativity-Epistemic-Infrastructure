Class: local engineering evidence. Date: 2026-10-15 JST. Run from GR-OS in
PowerShell. These commands reproduce the verified configurations; the adjacent
build/CTest logs retain actual outcomes, including earlier corrected failures.
Use a new log destination when repeating work to preserve accepted evidence.

```powershell
$taskCmake = 'C:/Program Files/Microsoft Visual Studio/2022/Community/Common7/IDE/CommonExtensions/Microsoft/CMake/CMake/bin/cmake.exe'
$taskCtest = 'C:/Program Files/Microsoft Visual Studio/2022/Community/Common7/IDE/CommonExtensions/Microsoft/CMake/CMake/bin/ctest.exe'

& $taskCmake -S . -B build -G 'Visual Studio 17 2022' -A x64 -DGR_BUILD_DATA=ON -DGR_BUILD_BENCHMARKS=ON -DGR_REQUIRE_PYTHON_TESTS=ON -DGR_TEST_TIMEOUT_MULTIPLIER=1
```

The installed SDK case builds an offline wheel using the existing local packaging
environment, stages a relocated native installation and compiles/runs external
C/C++ consumers, Python and CLI examples. It needs local setuptools/wheel; the
test does not download them. The final accepted prefix is `build/p/ccf4fa6d/`.
The Release Python interpreter has optional NumPy 2.5.0 installed.
