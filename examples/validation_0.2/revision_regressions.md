# Discriminating cases for the 0.3 corrections

**Class:** Informative synthetic review fixture  
**Status:** EXPERIMENTAL; 2026-09-22  
**Basis:** [0.2 findings and 0.3 dispositions](../../docs/reviews/validation_0.2/README.md)

These cases distinguish the intended interpretation of the revised clauses. The comparison is an authored-text review. It does not report a real election, institutional action, transfer, historical occurrence or observed user performance. The separate P0 numerical results are recorded by the executed arithmetic checker.

## RG-01 — An attempted ballot is not silence

Five eligible participants are represented. Two have valid approvals, one a disapproval, one an abstention, and one only an attributable unresolved attempted submission. The tally has `Y=2`, `D=1`, `A=1`, `R=4`, `I=1`, `U=0`, `N=5`.

The numerical conditions pass, but an unresolved validity/handling issue still needs disposition. Calling the fifth person a nonrespondent loses the attempt; treating the attempt as an abstention changes the valid return count. Revised D1-032 preserves `N=R+I+U` and D1-074 preserves the clarification and challenge history. A valid replacement moves that person into `R` and out of `I`. Multiple submissions from one person do not become multiple persons. An unattributable message remains separately inventoried.

**Text-review result:** the revised provisions express these distinctions without changing D1-031. Actual verification, participant identity and challenge handling remain untested.

## RG-02 — No mapping does not remove a general safeguard

Candidate account A states that the six recording roles are ultimate constituents of reality and provides no metamodel mapping. Candidate B preserves operational roles separately and makes no mapping claim.

Both lack a mapping, but that fact concerns only the conditional mapping component of V100-011. Candidate A still violates the general separation. The revised Annex A assessment row asks the general question before considering whether a mapping-specific check is applicable.

**Text-review result:** the revised assessment instruction no longer permits the whole requirement to be skipped because a mapping is absent. This result does not settle any metaphysical thesis.

## RG-03 — An actual effect can have disputed attribution

An account represents an effect as realized, its evidence as retrospective inference, and the proposed contributor's attribution as disputed. These are three distinct statements. A single exclusive list containing `realized`, `inferred` and `disputed` would make the combination impossible or obscure its meaning.

**Text-review result:** revised R110-012 permits the combination and separately requires explicit unresolved actuality where applicable. The case tests representational distinctions; it does not establish the effect or the contributor's actual role.

## RG-04 — A transfer does not establish recirculation

A proposed return account contains the following authored components:

| Stage | Supplied assertion | Grounds and uncertainty |
|---|---|---|
| Initial generation | A maintenance collaboration is reported to have sustained monitoring | A participant's account; extent and alternatives unresolved |
| Conversion/transfer | A sponsor proposes returning resources to the collaboration | A fictional proposal; no delivery evidence |
| Return path | The proposal names a recipient route | Feasibility and actual receipt unverified |
| Later generative conditions | Continued maintenance capacity is an intended effect | No follow-up evidence of realization |

Candidate A summarizes the proposal as proof that regenerative capacity was restored. Candidate B retains the four stages, their connections and the stated uncertainty, and presents capacity renewal as intended and unverified.

**Text-review result:** R110-112 and the revised semantic/assessment schedules require these distinctions when recirculation is asserted. Candidate A's conclusion is not supported by the represented stages. Candidate B supplies a bounded, uncertain account; this is not a finding that recirculation occurred or that every GR-110 obligation is fulfilled. If no recirculation claim is made, R110-112's trigger is absent while other applicable return requirements remain assessable.

## RG-05 — A definition reference does not import an unstated certification

A GR-210 case uses GR-100 meanings and supplies a bounded GR-200 claim package. It makes no independent claim of GR-100 vocabulary-application conformity. The revised GR-210 reference identifies exactly the imported meanings, while C210-030 continues to require the applicable GR-200 package obligations.

**Text-review result:** the dependency scope is explicit. Neither a claim-field-only check nor the absence of a separate GR-100 conformity declaration substitutes for assessment of the required GR-200 package.
